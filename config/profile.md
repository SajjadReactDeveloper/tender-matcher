# Company profile: Funavry Technologies

Edit this file any time. It is read at the start of every run and used to decide which tenders match us.

## What we do
Funavry Technologies is a software development and IT services company focused on innovation, quality and reliable delivery.

Core services:
- Enterprise software development: custom web, mobile and IoT applications; UI/UX design
- System integration: consolidating disparate applications and technology products securely
- ERP implementation and managed application services (Oracle Fusion, CRM, HRMS, billing, land-asset and manufacturing ERPs)
- Digital transformation and automation: RPA, workflow and business-process digitisation, business-process outsourcing
- AI, machine learning, deep learning and big data: document classification and data extraction (OCR), claims automation, computer vision (number-plate recognition, vehicle classification, pose detection), recommendation systems
- AR/VR and 3D training simulations
- IoT and cloud computing: end-to-end IoT solutions, cloud applications
- Blockchain: authentication, identity governance (SailPoint), crypto wallets, NFT marketplaces
- Healthcare software: EHR, e-prescription, appointment scheduling, diagnosis support
- Marketplaces, e-commerce, CMS and news platforms, streaming

## Tenders we want (a match if any of these apply)
- Software development, web or mobile apps, portals, MIS, ERP, HRMS, CRM, e-governance, e-procurement systems
- System integration, digital transformation, automation, RPA
- AI/ML, data analytics, computer vision, OCR and document digitisation, surveillance analytics
- IoT, cloud hosting and migration, cybersecurity and identity/access projects
- Healthcare IT, education IT, AR/VR training
- Software maintenance, managed IT services, IT support outsourcing, BPO and data-entry/digitisation services
- IT and software consultancy, feasibility studies, technology advisory, RFPs and EOIs for any of the above

## Not a match
- Civil works, construction, repairs, roads, buildings
- Medicines, medical consumables, laboratory chemicals and glassware
- Food, uniforms, stationery, furniture, vehicles, fuel, ammunition, mechanical spares and tools
- Generic supplies with no IT or software content
